# AI-Powered Playwright Automation Framework

## 📌 Project Overview

This project is an AI-powered test automation framework built using
Playwright and JavaScript.

The framework is designed to automate web application test cases,
generate execution reports, and use AI to analyze test failures and
provide possible root causes and suggested fixes.

## 🛠️ Tech Stack

- JavaScript
- Playwright
- Node.js
- npm
- Page Object Model (POM)
- API Testing
- OpenAI / LLM Integration
- Allure Report
- Git & GitHub
- Jenkins
- MCP (Explored)
